# Carlos Guerrero — Developer Portfolio

Personal website and portfolio showcasing backend and full-stack projects, built with HTML5, CSS, and Vanilla JavaScript. Hosted on GitHub Pages at [https://CHW1534.github.io](https://CHW1534.github.io).

## Overview

- **Stack:** HTML5, CSS3, Vanilla JavaScript (ES6+), GitHub REST API.
- **Features:** Responsive dark/light theme, interactive project showcase with category filtering, dynamic GitHub API repository stats, and printable CV layout.

## Running Locally

Open `index.html` directly in any web browser or run a simple local web server:

```bash
python -m http.server 8000
```
