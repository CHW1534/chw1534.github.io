## 📦 Instrucciones para Publicar en GitHub Pages

1. Abre la terminal en esta carpeta (`c:\Users\CHW\GITPAGES`).
2. Confirma y añade los cambios a git:
   ```bash
   git add .
   git commit -m "Feat: nuevo portafolio profesional y CV interactivo"
   ```
3. Sube los cambios a tu repositorio `CHW1534/chw1534.github.io`:
   ```bash
   git push -u origin main
   ```
4. En GitHub, ve a **Settings > Pages** de tu repositorio `chw1534.github.io`.
5. Asegúrate de que la fuente esté configurada en **Deploy from a branch** y selecciona la rama `main` / `/(root)`.
6. En un par de minutos, tu sitio estará vivo en **https://CHW1534.github.io**!
